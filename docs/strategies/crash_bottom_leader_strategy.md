# crash_bottom_leader 策略规格与回测（v1.1）

日期：2026-08-18 | 数据：2015-01-01 ~ 2026-07-31（11.5 年）

## 1. 策略定义（完整规格）

| 层 | 规则 | 参数 |
|----|------|------|
| **市场状态** | 中证1000 指数 20 日累计收益 < -8% → 触发；恢复 → 空仓 | 阈值 -8%，窗口 20 日 |
| **入场缓冲** | 触发段（连续触发周）**首周空仓**，第 2 周起入场（v1.1 新增） | — |
| **选股** | 触发周按因子 signal（超跌秩 + 市值龙头秩）降序取 top K | K = 20 |
| **权重** | 等权（1/K） | — |
| **调仓** | 周频（周五对齐），触发期每周按最新信号换仓 | 换手 = 新增/K |
| **可交易性** | 买入日跌停（pct_chg <= -9.8%）的股票排除（买不进） | 硬约束 |
| **成本** | 双边 35bps = 佣金 2.5×2 + 印花税 5（卖出）+ 冲击 10×2 | — |
| **退出** | 掩码恢复 0 自动清仓；空仓期收益 0 | — |

**与因子信号的关系**：策略是因子（`crash_bottom_leader_timed`）的可执行化——
因子层回答"信号是否有横截面预测力"（RankIC/分层），策略层回答"按信号真实
交易能赚多少"（组合/成本/可交易性）。

## 2. 策略 vs 因子：三个转化损失（本策略实测）

| 损失来源 | 机制 | 实测影响 |
|---------|------|---------|
| **多头 beta** | 因子层 long_short 夏普 2.21 靠融券对冲；策略只能做多 | 触发期波动 50% → 组合夏普 1.19 |
| **成本** | 周频换仓 74.5% 换手 × 35bps 双边 | 年化 81.1% → 58.3%（-23pp） |
| **可交易性** | 信号最强的股票往往正跌停买不进（纸面收益） | **反而改善**：过滤后年化 +20pp（58.3% vs 37.7%）——不可交易股的理论收益是"诱饵" |

**可交易性发现（重要）**：因子评估把跌停股计入理论收益，而跌停股（信号最强
的）恰恰买不进。过滤后信号次强的可交易股票收益质量更高——策略化不仅
"打折"，还纠正了因子的系统性高估。

## 3. 回测结果（跌停过滤 + 成本 35bps + 段首缓冲，v1.1）

| 指标 | 值 |
|------|----|
| 触发周 | 109（11.5 年，空仓 86% 时间） |
| 累计净值 | **3.13**（2015-06 起，换手成本全口径） |
| 触发期年化（口径见下） | **72.3%** |
| **全期年化**（含空仓期） | **10.4%** |
| 触发期夏普 | **1.59** |
| 最大回撤（真实路径） | 16.2%（**蒙特卡洛典型 30-38%**，见 §3.3） |
| 总成本 | 19.9%（累计） |
| 平均换手 | 52.1%/周（调仓周；空仓周不换手） |

> **口径说明**：73.7% 是"触发期年化"（109 触发周 / 52 ≈ 2.1 年复利，
> 空仓期不参与）。资金全年占用视角的全期年化 = 3.13^(1/11.5) - 1 = **10.4%**。
> 两者都真实：触发期年化回答"用钱时赚多快"，全期年化回答"总资金回报"。

### v1.0 → v1.1：段首缓冲的效果

| 配置 | 年化 | 夏普 | 总成本 |
|------|------|------|--------|
| v1.0（无缓冲） | 58.3% | 1.19 | 28.4% |
| **v1.1（段首缓冲）** | **73.7%** | **1.62** | **18.1%** |

机制：触发首周市场仍在暴跌中（2018-06、2026-07 轮的首周即亏损来源），
跳过首周避开最危险的一周；且段首周换手 100%（全仓新买）是每次触发最贵的
一周，跳过直接省 ~10pp 累计成本。

### 3.3 蒙特卡洛模拟（bootstrap，1000 条路径）

采样单元：**33 个触发段**（block bootstrap，保留段内序列相关；`--mc-mode week`
周级 iid 对照分布相近）。真实路径与模拟分布对比：

| 指标 | 真实路径 | 模拟 p5 | p50 | p95 |
|------|---------|---------|-----|-----|
| 触发期年化 | 72.3% | 32.3% | **75.2%** | 137.9% |
| 全期年化 | 10.4% | 5.2% | **10.8%** | 17.1% |
| 夏普 | 1.59 | 0.77 | **1.69** | 3.40 |
| 最大回撤 | 16.2% | 11.7% | **37.6%** | 38.0% |
| 终值 | 3.13 | 1.80 | **3.24** | 6.15 |

**风险概率**：触发期年化 ≤ 0 仅 0.1%、<10% 仅 0.5%；**回撤 > 30% 概率 74.4%**；
夏普 < 1 概率 11.7%。

**三个结论**：

1. **收益特征稳健**：真实触发期年化/夏普/终值全部落在 bootstrap 中位数附近——
   73.7% 不是运气，段收益分布支撑同水平收益（p5 也有 32%）。
2. **全期年化 ~11% 是策略定位的真相**：作为"危机应对层"，触发期 75% 年化
   极强；作为"全天候主策略"，空仓 86% 摊薄到 ~11%（≈ 货基 + 触发增强）。
3. **真实路径回撤 16.2% 是段序运气**：bootstrap 典型路径回撤 30-38%（74% 概率
   >30%）——2015 大段在早期贡献主要收益恰好压低了回撤；段序随机化后回撤
   显著放大。展示回撤应使用典型值（~35%）而非真实路径值。

### 已证伪的变异（记录）

- **触发强度分级仓位**（w = min(1, -mkt20/0.16)，深跌重仓）：年化 15.9%、
  夏普 0.45——严重证伪。股灾**深度与反弹非线性**：V 型浅跌（-8% 一周内）
  反弹最猛、阴跌深跌（-16% 缓慢累积）继续磨底；线性映射恰好错配。
- **段内回撤止损**（10/15/20%）：夏普升（1.92@10%）但年化大降
  （73.7% → 62.8%）——唯一止损段是 2015 股灾 33 周段（熔断期回撤 -20%+
  触发止损，错过段内后期 +24% 反弹）。**止损无法区分"段内波动"（盈利段
  正常震荡）与"段内失败"（2018-06 亏损段）**——幅度过滤不如段首缓冲的
  时间过滤。保留为可选风控（`--stop-loss 0.10` 夏普最优），不作默认。

### 已证伪的变异（个股级止盈止损持仓管理）

- **止盈/止损/最长持有规则**（`--take-profit 0.15 --stock-stop-loss 0.10
  --max-hold 8`）：换手 52%→17%、成本 20%→6.6%（稳定换手目标达成），但
  触发期年化 72.3%→**18.6%**、夏普 1.59→0.48。两个机制：
  1. **止盈截断右尾**——反弹收益极度右偏（少数龙头贡献大头），+15% 止盈
     恰好砍掉最大收益来源；超跌反弹是"反弹到位就走"，不是"让利润奔跑"；
  2. **锁死轮动**——买入后持有到目标，错过持续出现的新超跌机会；周频的
     alpha 本质是"每周换入最新超跌股"的信号驱动轮动。
  **结论：周频调仓对超跌反弹是必要机制，不是可降的成本**；固定幅度止盈
  与信号驱动轮动机制互斥。
- **买入门槛**（`--k-buy 10`，买入要求高于卖出）：换手进一步降（14%）、
  成本 5.3%，但收益再降（12.0%）——补仓池限前 10 名买在反弹末端的高位
  （信号滞后的强股）。证伪。

### 策略级经验（多轮验证）

- **时间过滤优于幅度过滤**：段首缓冲（跳过首周）双赢 +15pp 年化；止损
  （回撤退出）误杀盈利段——失败与波动的区分在**时间维度**而非幅度维度。
- **轮动是超跌反弹的 alpha 来源**：周频换仓（换入最新超跌股）不可替代——
  固定持仓（rebalance>1、止盈止损规则）都因错过轮动而收益减半以上。

### 触发明细（主要轮次）

| 起 | 止 | 周数 | 累计收益 |
|----|----|------|---------|
| 2015-06-26 | 2016-02-05 | 33 | +14.1%（股灾+熔断全程） |
| 2018-02-02 | 2018-02-23 | 4 | +17.2% |
| 2018-10-12 | 2018-11-09 | 5 | +16.3% |
| 2022-04-22 | 2022-05-06 | 3 | +22.4% |
| 2024-01-19 | 2024-02-08 | 4 | +7.9%（微盘危机） |
| 2026-07-17 | 2026-07-31 | 3 | -11.0%（未完成反弹，回撤主要来源） |

**触发不等于立即可抄**：2018-06 是熊市中继、2026-07 是未完成段。

## 5. 局限与下一步

- **调仓频率未优化**：周频 + 74.5% 换手是成本主因（总成本 28%）——持有期拉长
  （2 周）或半仓滚动可显著降本，未做（避免参数扫描）。
- **K 未优化**：top 20 是惯例值。
- **无止损**：触发期个股不设止损（2018-06 熊市中继轮全组合 -16%）。
- **冲击成本低估**：35bps 冲击假设在股灾流动性枯竭期可能偏低（跌停过滤已
  部分对冲）。
- **基准缺失**：未与中证1000 同期对比（触发期 58% 年化 vs 指数暴跌段）。
